Bring your own profile

  1. Install SPT, then extract the client mod pack below into that folder. Start your own SPT once so the profile is saved, then close your local server and the game.
  2. Connect Tailscale. Profile import is jianq-7900xtx.tail4219b.ts.net:6970, not the game port 6969. The first time, open the import connection and accept the certificate. Then choose your own file from SPT/user/profiles. The file name is your profile id. Leave every other file there.
  3. After the page confirms the import, wait about a minute. The game server reloads so it can see the new profile. Imports are blocked while anyone is in an active raid so ongoing raids are never interrupted.
  4. Open the launcher, select this server, and log in with the same username. SPT 4.1 identifies a profile by username, so keep that name private.

The file goes from your browser to the server over Tailscale. It is not stored on GitHub. If that same profile is already on the server, the page asks before replacing the saved file (and keeps a server-side backup of the previous file). An upload still cannot take a username that belongs to a different profile. If your profile contains items or traders from mods not installed on this server, SPT automatically strips those orphaned entries on load so your profile still boots cleanly.

After the profile is on the server, play it here only. Running the same profile on your own server at the same time will split your progress.

Hosting a raid

Standalone player-hosted raids are always available: leave Use Headless Host unticked to host on your own PC.

When a headless raid host is online, you can tick Use Headless Host on the raid screen so everyone connects as a client. When no headless client is online (or one is already busy), leave it unticked and host normally on your PC.

If you see "Your client doesn't meet server requirements"

Fika checks your loaded plugins and DLL hashes at login so mismatched mods fail cleanly at the menu instead of crashing or desyncing a raid. If you see that screen:

  1. Open SPT\BepInEx\LogOutput.log and search for FikaModHandler. It lists exact missing required, forbidden, or mismatched mod GUIDs.
  2. Remove any extra plugins not listed under Required or Optional below.
  3. Re-download the current client mod pack above and extract it cleanly over your SPT folder (delete old BepInEx\plugins\mpstark-dynamicmaps if upgrading from 1.2.1).

How access is limited

  • The game port is for Tailscale members and the home LAN. It is not published to the internet from this setup.
  • The server web admin login is a separate password, works from the server itself, and is not written on this page.
  • Profile files, server configs, and API keys stay off this website.
  • The import page only accepts a profile from this website, and only while you are on Tailscale or the home LAN. Another website cannot submit one through your browser.
  • Replacing a profile asks for confirmation first, backs up the previous copy on the server, and only rewrites that same profile file. It cannot take a username that belongs to a different profile, and imports are refused while anyone is in an active raid.
  • The download box lists player usernames already on the server so you can pick yours. The file it returns is only the profile for the name you choose.
  • Online now shows the nickname of someone connected at the moment. It does not list saved profiles or profile files.
  • The client mod pack is a direct file on the Tailscale address. It is not published from this website.
