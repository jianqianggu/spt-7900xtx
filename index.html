SPT server

Shared SPT 4.1.6 server for invited players. Bring the profile you already play, then join from the SPT launcher.

What you need installed

  • Escape from Tarkov 0.16.9.5.40743
  • SPT 4.1.6
  • Fika client 2.4.2, the same co-op mod the server is running
  • The client plugins listed below, at the same versions

Connect

In the SPT launcher, add a server and use one of these addresses. The launcher connects with HTTPS. The first time you connect, accept the server certificate. Use the first address if you were invited on Tailscale. Use the second only when your PC is on the same home network as the server.

jianq-7900xtx.tail4219b.ts.net:6969

Same home network

192.168.0.12:6969

There is no public internet address. A Tailscale invite comes from the server admin in private. This page is not an invite. The import below only works while Tailscale is connected.

Bring your own profile

  1. Install the SPT version and client mods on this page. Start your own SPT once so the profile is saved, then close your local server and the game.
  2. Connect Tailscale. The first time, open the import connection and accept the certificate. Then choose your own file from SPT/user/profiles. The file name is your profile id. Leave every other file there.
  3. After the page confirms the import, wait about a minute. The game server reloads so it can see the new profile.
  4. Open the launcher, select this server, and log in with the same username. SPT 4.1 identifies a profile by username, so keep that name private.

The file goes from your browser to the server over Tailscale. It is not stored on GitHub. A profile that reuses someone else's username is refused, and an upload cannot replace a profile already on the server.

After the profile is on the server, play it here only. Running the same profile on your own server at the same time will split your progress.

How access is limited

  • The game port is for Tailscale members and the home LAN. It is not published to the internet from this setup.
  • The server web admin login is a separate password, works from the server itself, and is not written on this page.
  • Profile files, server configs, and API keys stay off this website.
  • The import page only accepts a profile from this website, and only while you are on Tailscale. Another website cannot submit one through your browser.
  • An imported profile cannot overwrite a different person's username or replace a profile already on the server.
