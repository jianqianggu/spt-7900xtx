Connect

In the SPT launcher, add a server and use one of these addresses. The launcher connects with HTTPS. The first time you connect, accept the server certificate. Use the first address if you were invited on Tailscale. Use the second only when your PC is on the same home network as the server.

There is no public internet address. A Tailscale invite comes from the server admin in private. This page is not an invite. The import below only works while Tailscale is connected.

Bring your own profile

  1. Install SPT, then extract the client mod pack below into that folder. Start your own SPT once so the profile is saved, then close your local server and the game.
  2. Connect Tailscale. Profile import is jianq-7900xtx.tail4219b.ts.net:6970, not the game port 6969. The first time, open the import connection and accept the certificate. Then choose your own file from SPT/user/profiles. The file name is your profile id. Leave every other file there.
  3. After the page confirms the import, wait about a minute. The game server reloads so it can see the new profile.
  4. Open the launcher, select this server, and log in with the same username. SPT 4.1 identifies a profile by username, so keep that name private.

The file goes from your browser to the server over Tailscale. It is not stored on GitHub. If that same profile is already on the server, the page asks before replacing the saved file. An upload still cannot take a username that belongs to a different profile.

After the profile is on the server, play it here only. Running the same profile on your own server at the same time will split your progress.

Download your latest profile

Pick your username, or start typing and choose it from the list. The download is the last copy the server saved for that name.

How access is limited

  • The game port is for Tailscale members and the home LAN. It is not published to the internet from this setup.
  • The server web admin login is a separate password, works from the server itself, and is not written on this page.
  • Profile files, server configs, and API keys stay off this website.
  • The import page only accepts a profile from this website, and only while you are on Tailscale. Another website cannot submit one through your browser.
  • Replacing a profile asks for confirmation first, and only rewrites that same profile file. It cannot take a username that belongs to a different profile.
  • The download box lists usernames already on the server so you can pick yours. The file it returns is only the profile for the name you choose.
  • Online now shows the nickname of someone connected at the moment. It does not list saved profiles or profile files.
  • The client mod pack is a direct file on the Tailscale address. It is not published from this website.
